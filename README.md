# Build-Agent-That-Can-Act-Hackthon
AI Interview Agent

The AI Interview Agent is a mock interview practice platform designed to help candidates prepare for technical interviews in a structured, realistic, and stress-free environment. Preparing for interviews on your own can be difficult, and arranging real mock interviews with mentors or peers is often time-consuming and hard to schedule. This project solves that problem by giving anyone instant access to a consistent, on-demand interview practice partner powered by AI.

The agent conducts a structured 3-question interview session, consisting of 2 conceptual questions and 1 coding question, tailored to the role the candidate is preparing for (for example, Frontend Engineer). It strictly follows a one-question-at-a-time format, meaning it will not move on to the next question until the candidate has submitted a complete answer to the current one. This mirrors the pacing of a real interview and keeps the candidate focused on one problem at a time instead of being overwhelmed with the full question set upfront.

Once all three questions have been answered, the agent performs a full, end-to-end evaluation of the candidate's performance. This includes an assessment of technical understanding, code quality (for the coding question), communication clarity, and overall interview readiness. The final output is a detailed summary highlighting the candidate's strengths, areas for improvement, and specific takeaways, along with suggestions for what to practice next — such as moving on to mid-level questions or exploring system design topics.

The agent is built on the gemini-3-6-flash model, configured with a low reasoning effort setting for fast, responsive interactions, along with dynamic sub-agents, generative UI, and user-question capabilities enabled to make the interview feel interactive and adaptive rather than scripted.

This project was built with the help of OpenAI's GPT and Google Gemini tools, which were used to design and refine the agent's instructions, question logic, and evaluation criteria throughout development.
